# Depths of Shadow Reflections — Version 2

A mobile-first progressive web app for guided self-reflection and shadow-work journaling.

## Version 2 includes
- Home dashboard
- 30-day guided shadow journey
- Private local journal history
- Favorite journal entries
- Emotional vocabulary check-ins
- Trigger and projection reflection
- Parts-based reflection prompts
- Boundary clarity exercises
- Grounding practice
- Integration exercises
- Progress dashboard
- Local data export and erase controls
- Offline support through a service worker
- Installable PWA behavior where supported

## Privacy
This build stores journal entries and app progress locally in the browser on the user's device using localStorage. It does not send that journal content to a server.

## Important
This is an educational self-reflection tool and is not therapy, diagnosis, crisis support, medical advice, or legal advice.
